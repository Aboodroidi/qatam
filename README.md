# حسابات المزرعة — Qatam Farm

نظام مالي بسيط لشريكين في المزرعة (**أبو عبدالرحمن** و **أبو عبدالله**).
كل شريك يرفع إيصالاته (المبلغ + التاريخ + الفئة + صورة)، والنظام يجمع الإجماليات ويعرضها،
وتظهر التحديثات مباشرةً عند الطرفين لأنهما متصلان بنفس قاعدة البيانات.

---

## ما الذي ستحصل عليه
- شاشة تختار فيها من أنت (أبو عبدالرحمن / أبو عبدالله).
- بطاقات إجمالي: إجمالي كل شريك + الإجمالي الكلي.
- زر «إضافة إيصال» يفتح نموذجًا لإدخال المبلغ والتاريخ والفئة وصورة الإيصال.
- قائمة بكل الإيصالات مع صورها، وإمكانية الحذف والفلترة حسب الشريك أو الفئة.
- **مزامنة لحظية**: أي إيصال يضيفه أحد الشريكين يظهر فورًا عند الآخر.
- **قراءة الإيصال تلقائيًا (ذكاء اصطناعي)**: عند اختيار صورة أو التقاطها، يقرأ النظام
  الإيصال ويعبّئ المبلغ والتاريخ والفئة واسم المتجر تلقائيًا — وتراجعها قبل الحفظ.

---

## خطوات التشغيل (مرة واحدة)

### 1) أنشئ مشروع Supabase مجاني
1. ادخل على <https://supabase.com> واضغط **Start your project** وسجّل الدخول.
2. اضغط **New project**، اختر اسمًا (مثل `qatam-farm`)، وكلمة مرور لقاعدة البيانات، ثم **Create**.
3. انتظر دقيقة حتى يجهز المشروع.

> ملاحظة: إنشاء الحساب تعمله أنت بنفسك — لا يمكنني إنشاؤه نيابةً عنك.

### 2) أنشئ الجداول
1. من القائمة الجانبية: **SQL Editor** ← **New query**.
2. افتح ملف `schema.sql` الموجود هنا، وانسخ محتواه كاملًا والصقه.
3. اضغط **Run**.

### 3) أنشئ مخزن الصور
1. من القائمة الجانبية: **Storage** ← **New bucket**.
2. الاسم: `receipts`، وفعّل خيار **Public bucket** ✅، ثم **Save**.
   (سياسات الوصول لهذا المخزن مضمّنة في `schema.sql` وتُنشأ تلقائيًا.)

### 4) انسخ المفتاحين إلى `config.js`
1. من القائمة الجانبية: **Project Settings** ← **API**.
2. انسخ **Project URL** و **anon public** key.
3. افتح ملف `config.js` والصقهما:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```

بهذا تعمل الحسابات الأساسية. جرّبه بفتح `index.html` (انظر الأسفل).

## تفعيل قراءة الإيصال تلقائيًا (Claude — اختياري لكنه مفيد)

القراءة التلقائية للإيصال تتم عبر **Supabase Edge Function** تحفظ مفتاح Anthropic
سرًّا (لا يظهر أبدًا في المتصفح أو على GitHub). النموذج المستخدم هو
`claude-haiku-4-5` (الأرخص، وكافٍ لقراءة الإيصالات).

### الإعداد لمرة واحدة
```bash
brew install supabase/tap/supabase        # تثبيت أداة Supabase
supabase login                            # تسجيل الدخول (يفتح المتصفح)
supabase link --project-ref <معرّف-مشروعك>  # ربط مشروعك
```
> معرّف المشروع تجده في رابط لوحة Supabase أو في Project Settings → General.

### خزّن مفتاح Anthropic كسرّ ثم انشر الدالة
```bash
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...   # مفتاحك من console.anthropic.com
supabase functions deploy analyze-receipt --no-verify-jwt
```
بهذا تصبح ميزة القراءة التلقائية جاهزة. المفتاح يُحفظ داخل Supabase فقط ولا يظهر
أبدًا في المتصفح أو على GitHub.

## كيف تفتح التطبيق وتشاركه مع الشريك

### تجربة محلية على جهازك
افتح Terminal داخل هذا المجلد ثم:
```bash
python3 -m http.server 8777
```
ثم افتح المتصفح على: <http://localhost:8777/index.html>

### نشره على الإنترنت عبر GitHub Pages (مجانًا)
1. أنشئ مستودعًا (repository) على <https://github.com> وارفع فيه ملفات هذا المجلد.
   (مجلد `supabase/` يمكن رفعه بأمان — لا يحتوي أي مفاتيح سرية، لكنه لا يعمل على
   الموقع؛ يُنشر عبر أداة Supabase كما في الخطوات السابقة):
   ```bash
   git init && git add . && git commit -m "farm accounts"
   git branch -M main
   git remote add origin https://github.com/<اسمك>/<اسم-المستودع>.git
   git push -u origin main
   ```
2. في المستودع: **Settings → Pages** ← اختر الفرع `main` والمجلد `/ (root)` ← **Save**.
3. بعد دقيقة ستحصل على رابط مثل
   `https://<اسمك>.github.io/<اسم-المستودع>/` — أرسله للشريك، وكلاكما يفتحه من جواله.

> ملاحظة: `config.js` يُرفع مع الموقع ويحتوي المفتاح العام (anon) فقط — وهذا طبيعي وآمن.
> مفتاح Anthropic السري لا يُرفع أبدًا؛ فهو محفوظ داخل Supabase.

## إعدادات يمكنك تغييرها (في `config.js`)
- `FARM_NAME` — اسم المزرعة الظاهر في الأعلى.
- `CURRENCY` — العملة (افتراضيًا «ريال»).
- `PARTNERS` — أسماء الشريكين.
- `CATEGORIES` — فئات المصاريف (علف، بذور، وقود، ...).

---

## ملاحظة أمنية مهمة
هذه أداة خاصة بسيطة بين شريكين. المفتاح `anon` يكون ظاهرًا في التطبيق (وهذا طبيعي في Supabase)،
والإعداد الحالي يسمح لأي شخص لديه رابط التطبيق بقراءة وإضافة الإيصالات.
هذا مقبول لاستخدام خاص بين طرفين موثوقين. إذا أردت لاحقًا حماية أقوى (تسجيل دخول بحساب لكل شريك)،
أخبرني وأضيف نظام مصادقة كامل.
